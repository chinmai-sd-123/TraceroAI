The playground sends your question to the API's demo knowledge base. The server
retrieves, answers and evaluates it, and the trace appears below. It needs
`TRACEROAI_PLAYGROUND_ENABLED=true` on the API it talks to; leave that off on anything
public, since it makes LLM calls without a key.
